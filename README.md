# Performance Management

One app for staff performance. Three modules:

- **KRA** - KPI Master, Monthly KPI Entry, Internal Feedback, HO PTS (master and entry), Manager Rating Employee,
  Employee Rating Manager, Rating Score Master, and the HO Traffic Light report.
- **Sales Traffic Light** - BDE, ASM, Home Care, Inshop and Gallery score sheets with coloured print formats.
- **Worker Driver Security TL** - Worker, Driver and Security score sheets.
